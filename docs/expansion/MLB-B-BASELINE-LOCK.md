## 2. 為什麼停 B 微調

已掃盡且否決／無效的方向包括：甜區硬切、保量軟路由、特徵軟罰、v4.5 權重縮放、rest／牛棚硬過濾、Kelly、混大小、TopK≥4 等。  
再動選注旋鈕，多半是 **砍場換勝率** 或 **加場稀釋**，不符合「基準穩定」目標。

## 3. 進化軌道（三選一主路徑）

### 路徑 α（建議）：B 凍結 + **A 作增量模組**（加場／抬體感勝率）

- **B 照舊下**（賺錢引擎，不動）。  
- **A 另開 profile／日配額**，與 B **分開回測、分開記賬**。  
- 產品層合併：「今日 B 取 1–2 + A 取 0–1」，**不是**把 A 門檻寫進 B 的 classify。  
- 警告：歷史 A（P≥55% + margin≥1）均賠~1.65、WF 不過、ROI 負——**禁止原樣復活當正式**。  
- 要接 A，必須先定義 **A′**（能過自身短賠損益平衡的版本），再談掛載。

### 路徑 β：B 凍結 + **特徵集重訓**（v4.6 實驗）

- 對準 miss 診斷（牛棚／近期負荷等現不在 16 特徵內）。  
- 新模型用**凍結選注**對照；不過閘不替換 v4.5。  
- 成本高、週期長；與 A 增量可並行，但不要同時改選注。

### 路徑 γ：整包停進化，只紙上實盤

- 基準包跑 OOS／實盤，累積樣本再決定 α 或 β。  
- 適合「先確認活體表現」時。

**不建議**：繼續在 B 上掃門檻／軟罰／權重縮放（已平台）。

---

## 4. 接 A 時的硬約束

1. B 常數本包 **零改動**。  
2. A′ 必須單獨過：自身 breakeven、雙窗、WF；合併美元不得靠「吃掉 B 正期望場」灌水。  
3. 與 B 撞場時：**優先保留 B**（或明確規則：同場只取一邊並記標籤）。  
4. 體感勝率上升若來自短賠，必須同時報告 **合併 ROI／總美元**，避免「準但虧」。
